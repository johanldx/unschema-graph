# Visual identity

Concept A was selected: its paired brackets communicate structured data while the offset
blocks and connector communicate composition into a graph. Concept B remains as the
documented alternative.

- Clear space: at least one block width (13/64 of the mark) on every side.
- Minimum size: 16 px for the mark; 120 px for the horizontal wordmark.
- Light/dark use: the UI component uses `currentColor` for the connector and brackets;
  the standalone light asset uses graphite. The monochrome form is concept A with one ink.
- Instrument Sans: variable 400–700, Latin + Latin Extended WOFF2, OFL-1.1.
- Commit Mono: static 400 and 600, Latin WOFF2, OFL-1.1.
- Required glyph sample: `Élévation — cœur / Type<T> { "@id": "#nœud" }`.

Font packages retain their license files in `node_modules` and are bundled locally by Astro;
no third-party font request is made.
